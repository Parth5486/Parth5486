## Nostrum Fashion: Shopify storefront work

Selected website features and theme components I have worked on for [Nostrum Fashion](https://www.nostrumfashion.com/):

- **Collection browsing:** Responsive product cards with swipeable image galleries on mobile, arrows on desktop, image dots, filters, and quick-add interactions.
- **Product pages:** Size-option labels for tracked variants with 1–5 units left, plus a custom Shiprocket delivery estimator with pincode entry and a clear delivery-date result.
- **Watch & Buy:** Draft stock-aware logic for tagged video products, with an “Out Of Stock” label and a Kbite “Notify Me” path for unavailable items.
- **Cart experience:** Matching five-checkpoint reward progress displays on the cart page and in the cart drawer.
- **Shop the Look and Style Week:** Configurable editorial looks with image browsing, variant selection, and multi-product add-to-cart flows.
- **Responsive storefront design:** Glass-style header work, footer layout refinements, and mobile collection-page usability changes.

This includes live and draft theme work. Some components have only been verified locally and should not be read as deployed features. The separate bundle-builder source is already in [shopify-bundle-pages](https://github.com/Parth5486/shopify-bundle-pages).
